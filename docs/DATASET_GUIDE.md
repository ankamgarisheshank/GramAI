# GramAI Dataset Guide

## 1. Directory Structure
- `raw/`: Unprocessed source files (CSV, JSON, PDF).
- `processed/`: Cleaned, normalized datasets ready for chunking.
- `metadata/`: Separate metadata linkages for dynamic filtering.
- `embeddings/`: Cached vector stores generated by the Embedding pipeline.
- `validation/`: Output logs of missing fields or corrupted data entries.

## 2. Core Schemas
### Scheme Schema
- **Scheme ID**: UUID
- **Scheme Name**: str
- **Department**: str
- **Eligibility**: Array[Rule]
- **Income Limit**: float
- **District Applicability**: Array[DistrictID]
