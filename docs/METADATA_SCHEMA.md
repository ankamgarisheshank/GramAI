# Metadata Schema

Every vectorized document chunk contains the following metadata to ensure RAG precision:

```json
{
  "Category": "Agriculture | Education | Health",
  "Department": "Govt Dept Name",
  "District": "Target District | All",
  "Beneficiary_Type": "Farmer | Student | Widow",
  "Source": "URL",
  "Version": "YYYY-MM-DD"
}
```
